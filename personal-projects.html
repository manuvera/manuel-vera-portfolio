PROJECT 01

Owl — Room Monitoring Sensor

An ESP32-based room monitoring sensor developed to capture room activity, temperature, humidity and light data and log the information into a Home Assistant dashboard.

CONCEPT

Turn a small sensor into a useful room-monitoring system

The objective was to build a compact sensor capable of monitoring several characteristics of a room rather than collecting a single measurement.

The project combines room activity, temperature, humidity and light sensing and makes the information available in Home Assistant so the data can be viewed over time.

TECHNOLOGY

Sense locally, collect centrally

The Owl sensor is built around an ESP32, with the sensing functions and data path integrated into the home-automation environment.

PROJECT 02

SportPods — Soccer Training System

An in-development connected training system using ESP32-based pods, LED matrices and proximity sensing to create soccer drills and measure speed and agility.

CONCEPT

Turn training drills into a connected system

The idea behind SportPods is to create small, connected training pods that can be positioned around a soccer field and used to build repeatable drills.

Each pod provides a clear visual instruction through an LED matrix, detects when a player is in close proximity, communicates with other pods and provides measurements that can be used to evaluate speed and agility.

ARCHITECTURE

Small autonomous pods, coordinated wirelessly

The system is being designed around an ESP32-S3 architecture. ESP-NOW is used for communication between pods and a master pod, while Bluetooth is used by the master pod to transfer collected data to a phone.

PROJECT MATERIAL

SportPod V1 Wiring Architecture

The V1 hardware architecture combines the ESP32-S3 controller, LED matrix, VL53L0X proximity sensor, level shifting and a battery-powered 5 V supply.

SYSTEM CONCEPT

From individual pod to training network

The long-term concept is a set of portable pods that can be arranged into different drill sequences. A master pod coordinates the sequence while individual pods provide the player-facing instructions and sensing.

CURRENT STATUS

In development

Current work is focused on the pod hardware, power architecture, sensing, LED control and wireless communications. Software and drill-design capabilities will continue to evolve as the hardware is tested.
